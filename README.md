# Ryan’s Roofing Inc. — independent website concept

A bespoke, responsive static marketing demo. This is a redesign concept; the existing official website is https://ryansroofinginc.ca/. No business endorsement is implied.

## Run

Node 20+. No application dependencies. npm run build validates local assets and anchors, then creates dist/. npm run dev previews at http://localhost:4173.

## Contact and truthfulness

All forms prepare messages locally; nothing is sent, stored, booked, ordered or paid. Email links open the visitor’s email client. Phone and social links use public/source-report details. All imagery is licensed stock inspiration, not business work. No prices, policies, menu items, reviews, opening hours, certifications, response times or availability were fabricated. Current details are confirmed directly by the business.
